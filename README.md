## 📦 Орнату және Қолдану (Installation & Usage)

### 1. Барлық скиллдерді глобалды түрде орнату (Global Setup)
Кез келген жобада осы скиллдер қолжетімді болуы үшін `skills/` папкасын өз жүйеңіздің Gemini конфигурациясына көшіріңіз:

**Windows (PowerShell):**
```powershell
Copy-Item -Path ".\skills\*" -Destination "$HOME\.gemini\config\skills\" -Recurse -Force
```

**Linux / macOS (Bash):**
```bash
cp -r ./skills/* ~/.gemini/config/skills/
```

### 2. Белгілі бір жобаға ғана қосу (Workspace / Project Level)
Белгілі бір жоба ішінде ғана қолдану үшін жоба түбіріне `.agents/skills/` ретінде салыңыз:
```bash
mkdir -p .agents/skills
cp -r ./skills/telegram-ai-upscaler-bot .agents/skills/
```
